# 02｜プラン設計と「上位プランがお得に見える」見せ方

## 1. プラン構成（2本柱＋入口）

```
[入口] 無料 戦略診断（30分）
   ↓
[基本] LP完成プラン         198,000円
   ↓  （納品後30日以内は差額アップグレード可）
[上位] 商品化並走プラン      498,000円（or 月180,000円×3ヶ月）
```

### 入口｜無料 戦略診断（30分）
- 現状のLP・note・プロフィールURLを事前にもらい、成約率診断の観点で課題を3つに絞って伝える
- 売り込みではなく「診断結果」を渡す場。ここで設計の価値を体感させてから2プランを提示する
- ※既存LPがある人には特に刺さる導線（「きれいなのに反応がない」層）

### 基本｜LP完成プラン — 198,000円
「売れる設計図つきで、LPを1本、公開まで」

| 含まれるもの | 単品換算の目安 |
|---|---|
| 戦略設計ミーティング 90分 | 50,000円 |
| 事業設計図（コンセプト・導線・世界観の言語化） | 80,000円 |
| LP制作1本（コピー・画像・実装・レスポンシブ） | 100,000円 |
| 公開作業＋HTML一式納品（資産として手元に残る） | 20,000円 |
| 告知文セット（Threads3本＋LINE配信文） | 20,000円 |
| 修正2回＋納品後30日のチャット質問サポート | 30,000円 |
| **合計相当** | **300,000円** |

### 上位｜商品化並走プラン — 498,000円（3ヶ月）
「LPで終わらせず、商品ラインナップと導線ごと作り切る」

基本プランの全部に加えて：

| 追加で含まれるもの | 単品換算の目安 |
|---|---|
| 戦略ミーティング 月2回×3ヶ月（計6回） | 300,000円 |
| 商品ラインナップ設計（フロント→ミドル→バックの横展開） | 150,000円 |
| 追加LP 最大2本（新商品LP・LINE登録LPなど） | 200,000円 |
| 公開後の計測→改善（成約率診断＋改善実装 月1回） | 90,000円 |
| 媒体別の集客投稿設計（X / Threads / Instagram / LINE） | 60,000円 |
| 期間中チャット相談 無制限（営業日） | 60,000円 |
| **合計相当（基本プラン分含む）** | **1,160,000円** |

- 並走枠は**月2社まで**（1社あたりの稼働を確保するための実質上限。希少性の演出ではなく事実として書く）
- 支払いは一括498,000円 or 月180,000円×3（一括が18%お得、と明記して一括に誘導）

## 2. 上位プランがお得に見える見せ方（7つの仕掛け）

### ① 比較の軸を「価格」から「1成果あたり」にずらす
- 基本：LP1本で198,000円 → **1本あたり198,000円**
- 上位：LP最大3本＋コンサル6回で498,000円 → **LP1本あたり166,000円で、設計並走が全部ついてくる**
- 表の下に小さく「LPだけ3本頼むより、並走つきの方が安くなる設計にしています」と正直に書く

### ② 単品換算の合計を並べる（アンカリング）
比較表の最下段に「単品換算 300,000円相当 / 1,160,000円相当」を置き、実売価格との差分を視覚化する。上位は**66万円分の差**が生まれる構造にしてある。

### ③ 差額アップグレード保証（基本プランをリスクゼロの入口に変える）
「基本プラン納品後30日以内なら、**差額300,000円だけで**上位プランに移行できます」
→ 迷ったら基本でいい、と言い切れる。同時に「基本を選んでも損しない＝上位が本命」という無言のメッセージになる。実際、公開後に改善・横展開の必要性を体感したタイミングで刺さる。

### ④ 「公開してからが本番」という教育をプラン表の前に置く
LP論として本文中で先に伝える：LPは公開して、反応を見て、直してから成果が出る。
→ この前提を飲み込んだ読者にとって、「公開までの基本プラン」は未完に見え、「改善まで並走する上位プラン」が論理的な完成形に見える。**煽らずに構造で選ばせる。**

### ⑤ 回収シナリオを静かに数字で見せる
「上位プランで設計するバックエンド商品（例：15万円の講座）が**4本売れたら回収**です。3ヶ月の並走はそのための期間です」
収入保証と誤解される表現は使わない（「〜を保証します」はNG）。あくまで計算式の提示に留める。

### ⑥ 比較表の設計で上位をデフォルトにする
- 上位カラムに「おすすめ」バッジ＋主ボタン色。基本はゴーストボタン
- 比較表は「基本にないもの」が✕で並ぶ形にする（商品設計 ✕ / 公開後改善 ✕ / 追加LP ✕）
- カラム順は 基本 → 上位（左から右へ視線が流れた先が上位）

### ⑦ 向いていない人を正直に書く
「まずLPを1本持ちたいだけなら、基本プランで十分です」と明記する。
→ 誠実さが上位プランの売り込み臭を消し、逆に「事業として伸ばしたい人＝上位」という自己選別が起きる。参考3教材すべてに共通する「煽らない・静かなLPほど売れる」哲学と一貫させる。

## 3. 価格の根拠メモ（社内用）

- LP制作代行の相場：1本3〜10万円（教材内の記載）。デザイン実装だけならこの帯に飲まれる
- 本サービスは「設計コンサル＋制作＋公開＋改善」の統合なので、比較対象はLP代行ではなく**Webコンサル（月10〜30万円）**。その文脈で198,000円/498,000円は中央値
- ツール活用で制作原価（時間）は大きく圧縮できるため、粗利構造は良い。浮いた時間をミーティングの質（＝商品の主役）に投資する
- 実績が貯まるまでの立ち上げ期は「モニター価格 148,000円/398,000円（掲載許可と引き換え）」を先着3社で回し、通常価格の正当性を作る
