# 戦略設計型LP制作サービス 企画一式

手持ちの3ツールを組み合わせて「事前ミーティングの質で成果を出す、コンサル型のLP制作サービス」を立ち上げるための企画ドキュメント一式。

## 読み順

| ファイル | 内容 |
|---|---|
| [01_サービス設計書.md](./01_サービス設計書.md) | コンセプト、3ツールの役割分担、制作フロー、事前ミーティングの設計とヒアリングシート |
| [02_プランと価格の見せ方.md](./02_プランと価格の見せ方.md) | 基本プラン／上位プランの中身、価格設定、上位プランがお得に見える見せ方の設計 |
| [03_Codex用LP制作指示書.md](./03_Codex用LP制作指示書.md) | このサービス自体の販売LPを Codex（または Claude Code）に貼るだけで作れる完全指示書 |

## 前提となる手持ちツール

1. **dododo LP Prompt Builder（設計士GPT）** — 何を・誰に・どう見せれば売れるかを整理し、導線・世界観・ファーストビューを決めて、職人AI（Codex / Claude / Readdy）に渡す指示書を出す
2. **LP制作メーカー2点セット（ゆめ）** — コンテンツ販売LP／ショップ・店舗LPの設計書・コピー・FAQ・HTML化プロンプト・画像プロンプト・公開前チェックを生成（ショップ・店舗LPメーカーは制作代行での商用利用OK）
3. **画像LPメーカーPro（ゆめ）** — ヒアリング7問から画像ごとLPを生成。テイスト200種、あんしんチェック（誇大表現・薬機法）、Vercel公開、告知文セットまで

## サービスの核

> LP制作サービスの姿をした、商品・導線の設計コンサル。
> 事前ミーティングで「何を・誰に・どう見せて・どこへ進ませるか」を決め切るので、
> 納品物の主役は**事業設計図**。LPはそれが形になった副産物──に見えるくらい設計に価値を置く。
> だから高額でも成立する。
