## ここからコピー

あなたはLP実装の職人AIです。以下の指示書に従って、日本語の縦長LP（1ページ）を制作してください。
不明点があれば実装前に質問してください。指示書にない要素（架空の実績・レビュー・受賞歴など）を勝手に追加しないでください。

## 0. 成果物の仕様

- `index.html` 1ファイル＋ `assets/` フォルダ（画像・動画）で完結する静的LP
- CSS・JSはHTML内に記述（外部ライブラリ・CDN禁止。Google Fontsのみ可）
- スマホファースト。375px幅で崩れないことを最優先し、PCは max-width 1080px 程度の中央寄せ
- ヒーローは `assets/hero.mp4` があれば背景動画＋半透明オーバーレイ、なければ `assets/hero.jpg` にフォールバック
- 画像はすべて `assets/` 内の相対パス参照。存在しない画像は淡いグラデーションのプレースホルダ`<div>`にして、HTMLコメントで `<!-- ここに◯◯の画像 -->` と差し替え場所を明記
- JavaScriptはスクロール時の控えめなフェードインとスムーススクロールのみ。JS無効環境でも全文が読めること
- セマンティックなHTML（header / main / section / footer、見出し階層はh1→h2→h3）
- OGP（title / description / og:image は assets/ogp.jpg 参照）を設定

## 1. 商品情報

- サービス名：【サービス名（例：戦略設計LP工房）】
- 提供者：【名前・肩書き】
- 商品：LP制作サービス。ただし主役は制作ではなく「事前の戦略設計ミーティング」。商品・ターゲット・導線・世界観を決め切ってからLPを作るため、コンサルティングに近い成果が出る
- 価格：LP完成プラン【198,000円】／商品化並走プラン【498,000円（3ヶ月）】

- 想定流入元：Threads・Instagramのプロフィールリンク、紹介

## 2. ターゲット（この読者だけに書く）

商品やサービスは持っているが、見せ方で止まっている個人事業主・小さなお店・コンテンツ販売者。
- 過去にLPを自作（またはAIで生成）したが「きれいなのに反応がない」経験がある
- SNSで興味は持たれるのに、プロフィールのリンク先で取りこぼしている自覚がある
- 制作代行の相場は知っているが、「作って終わり」への不信感がある

読者の今の状態：「LPが必要なのは分かっている。でも、何をどう見せればいいかが自分でも決まっていない」

## 3. 世界観・デザイン指示

- キーワード：静かな知性、余白、誠実。**煽り要素は一切入れない**
- ベース：白〜生成り（#FAFAF7程度）、文字は濃紺グレー（#1F2933程度）
- アクセント1色のみ：深いブルーグリーン（#0F6B5C程度）。CTAボタンとバッジにだけ使う
- フォント：見出し=Noto Serif JP、本文=Noto Sans JP（Google Fonts）
- 余白は広め（セクション間 padding 96px 以上、スマホは64px）
- 装飾は罫線・番号・余白で作る。グラデーション多用・ネオン・カウントダウン・点滅は禁止

## 4. セクション構成と実文コピー

以下の12セクションを順番通りに実装してください。コピーは原則このまま使用し、調整する場合もトーン（静か・断定しすぎない・煽らない）を維持してください。

### S1. ファーストビュー
- メインコピー（h1）：`LPは、副産物です。`
- サブコピー：`売れる理由を先に設計してから、ページにします。`\
  `事前ミーティングで「何を・誰に・どう見せるか」を決め切る、戦略設計型のLP制作サービス。`
- CTAボタン：`無料戦略診断を受ける（30分・オンライン）`
- ボタン下に小さく：`診断だけのご利用も歓迎です。`

### S2. 共感（問題提起）
見出し：`きれいなLPなのに、反応がない。`
本文：SNSで興味を持ってもらえたのに、リンク先で止まる。AIでLPを作ってみたら、それっぽいのに、どこかで見た量産型になった。直してと頼んだら、別の場所が壊れた——。箇条書き3〜4個で読者の実体験を短く並べる。

### S3. 原因の再定義
見出し：`作れないのではなく、決まっていないだけ。`
本文：LPが成果を出さない原因は、デザインでも文章力でもなく、「何を・誰に・どう見せて・どこへ進んでもらうか」が決まっていないこと。AIは指定されなかった部分を平均で埋めるので、設計がないまま作ると必ず量産型になる。——この論理を4〜6文で。

### S4. 解決策（サービスの核）
見出し：`だからこのサービスは、ミーティングが主役です。`
本文：90分の戦略設計ミーティングで、商品の核・ターゲット・導線・世界観を決め切る。納品するのはLPだけでなく「事業設計図」。設計図はSNS投稿にも次の商品にも流用できる資産になる。LPは、その設計が形になったもの。
補足カード3枚：`事業設計図` / `完成LP＋HTML一式（あなたの資産）` / `公開後すぐ使える告知文セット`

### S5. 提供フロー（5ステップ）
番号付きの縦タイムラインで：
1. `事前アンケート` — 現状と「いいな」と思うサイトを共有
2. `戦略設計ミーティング（90分）` — 何を・誰に・導線・世界観を決め切る
3. `設計図の納品` — コンセプトシートとFV案からお選びいただきます
4. `制作・検品` — 「売れるLPの5チェック」で品質確認
5. `公開・納品ミーティング` — URL発行、告知文セットのお渡し、運用のご案内

### S6. 品質基準
見出し：`私たちが公開前に必ず確認する5つ`
`主役がひとつに絞られているか` / `誰向けか3秒で伝わるか` / `次の行動に迷いがないか` / `不安を先回りして消せているか` / `煽っていないか`
最後の1文：`煽るLPは、短期の反応と引き換えに信頼を削ります。私たちは作りません。`

### S7. 制作例
見出し：`制作例`
プレースホルダのサムネイルカード2〜3枚（`<!-- ここに制作例スクショ -->`）。**実在しない実績・数値・お客様の声を創作することは禁止。** 実例が入るまでは「制作例は無料診断の際にご覧いただけます」という1文のみ表示。

### S8. プラン比較（最重要セクション）
見出し：`プランは2つ。迷ったら、基本プランからで大丈夫です。`
2カラムの比較カード（スマホでは縦積み、上位を先に表示）：

**LP完成プラン — 198,000円（税込）**
- 戦略設計ミーティング90分／事業設計図／LP制作1本／公開作業＋HTML一式納品／告知文セット／修正2回＋30日質問サポート
- 単品換算 300,000円相当
- ボタン（ゴースト）：`まずは無料診断で相談する`

**商品化並走プラン — 498,000円（3ヶ月）** ←「おすすめ」バッジ＋アクセント色の主ボタン
- 基本プランのすべて＋戦略ミーティング月2回×3ヶ月／商品ラインナップ設計（フロント→バックの横展開）／追加LP最大2本／公開後の計測・改善 月1回／媒体別の集客投稿設計／期間中チャット相談無制限
- 単品換算 1,160,000円相当
- `LP1本あたり166,000円。設計並走つきで、単発より安くなる設計です`
- `並走枠は月2社まで（稼働確保のため）`
- ボタン（主）：`無料診断で空き枠を確認する`

比較カードの下に注記2行：
`※LP完成プラン納品後30日以内は、差額300,000円で商品化並走プランへ移行できます。`
`※まずLPを1本持ちたいだけの方には、LP完成プランで十分です。`

### S9. 回収の考え方
見出し：`高い買い物か、どうか。`
本文：`LPは公開してからが本番です。反応を見て、直して、はじめて成果が出ます。商品化並走プランで設計するバックエンド商品（例：150,000円の講座）なら、4件のご成約で費用を回収できる計算です。3ヶ月の並走期間は、そのためにあります。`
**「保証」「必ず」「誰でも」等の断定表現は使わない。**

### S10. FAQ（アコーディオン不可、全文表示）
- `商品がまだ固まっていなくても申し込めますか？` → むしろその段階が最適。ミーティングで一緒に決めるのがこのサービスです
- `デザインの希望を伝えられるか不安です` → 「いいな」と思うサイトを3つ集めていただくだけで大丈夫です
- `納期は？` → ご契約から公開まで目安2〜3週間です
- `修正は何回までですか？` → LP完成プランは2回、並走プランは期間中随時対応します
- `成果は保証されますか？` → 売上の保証はできません。売れる状態に近づける設計と改善を、誠実に行います

### S11. 提供者プロフィール
【名前】／【経歴・実績を1〜2文】／【なぜこのサービスをやるのか1〜2文】＋顔写真プレースホルダ（`<!-- ここにプロフィール写真 -->`）

### S12. クロージングCTA＋フッター
- 見出し：`まずは30分、現状を診断させてください。`
- 本文：`いまお持ちのLPやnote、プロフィールページを拝見し、課題を3つに絞ってお伝えします。診断だけで終わっても構いません。`
- CTAボタン：`無料戦略診断を申し込む` → 【公式LINEのURL】
- フッター：`特定商取引法に基づく表記`（リンクプレースホルダ）／`プライバシーポリシー`／コピーライト表記

## 5. 禁止事項

- 架空の実績・数値・お客様の声・受賞歴・メディア掲載の創作
- 「今だけ」「残り◯名」等の虚偽の希少性、カウントダウン
- 収入・成果の保証と受け取れる表現
- CTAの種類を増やすこと（全ボタンの遷移先は【公式LINEのURL】1つ）
- 英語の見出し多用（日本語ページとして作る）

## 6. 完成後にやること

1. ローカルでの表示確認方法を、初心者向けに1ステップずつ教えてください
2. 以下の公開前チェックの結果を報告してください：
   - スマホ幅(375px)でFV・比較表・ボタンが崩れていないか
   - すべてのCTAボタンの遷移先が正しいか
   - 価格・プラン内容に指示書との食い違いがないか
   - 架空の実績・煽り表現が混入していないか
3. Vercelで公開する手順を、初心者向けに1ステップずつ案内してください

## 7. 修正時のルール

修正依頼は1回に1箇所ずつ行います。依頼された箇所以外は変更しないでください。
