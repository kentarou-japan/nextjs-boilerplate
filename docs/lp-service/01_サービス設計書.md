# 01｜サービス設計書 — 戦略設計型LP制作サービス

## 1. コンセプト

**「LPを作る前に、売れる理由を作る」**

世の中のLP制作代行は「デザインと実装」を売っている。相場は1本3〜10万円で、価格競争になりやすい。
このサービスは逆で、**制作より前の設計（＝事前ミーティング）を商品の主役にする**。

- AIに丸投げしたLPが量産型になるのは、「何を・誰に・どう見せて・どこへ進ませるか」が決まっていないから
- そこをプロが並走して決め切れば、LPはほぼ自動的に「売れる形」で出てくる
- つまり顧客が受け取る本当の価値は **事業設計図（コンセプト・導線・世界観の言語化）** であり、LPはその出力結果

この構造なら「LP1本いくら」の相場と比較されず、コンサルティングの価格帯で売れる。
キャッチコピーの方向性：**「LPは、副産物です。」**

## 2. 3ツールの役割分担（裏側オペレーション）

| 工程 | 使うツール | 役割 |
|---|---|---|
| 設計 | dododo LP Prompt Builder | ヒアリングの型。何を作るか（LP/サイト）、誰に、導線、世界観、FVを決め、職人AI用の指示書を出す |
| 材料化 | LP制作メーカー2点セット | 設計図をLPの材料（設計書・コピー・FAQ・HTML化プロンプト・画像プロンプト）に変換。商品販売系は「コンテンツ販売LPメーカー」、店舗・サロン・予約系は「ショップ・店舗LPメーカー」 |
| ビジュアル | 画像LPメーカーPro＋LPビジュアルGPTs | FV画像・セクション画像・世界観画像の生成。テイスト200種から世界観を具体化 |
| 実装 | Codex / Claude Code | HTML化プロンプト＋指示書＋FV画像を渡して実装。構造が整理され後から修正しやすいCodexを標準ルートに |
| 検品 | 売れるLPの5チェック＋LP成約率診断GPTs | 主役1つ／誰向けか3秒／CTA迷いなし／安心材料／煽ってない、をQAループで確認 |
| 公開・告知 | Vercel＋告知文セット | 公開URL発行。Threads投稿3本＋LINE配信文まで納品物に含める |

ポイント：**顧客にはツール名を見せない。** 顧客が見るのは「質の高いミーティング」と「設計図」と「完成LP」だけ。ツールは原価を下げ、納期を短くするための内部装備。

## 3. 提供フロー（顧客体験）

### STEP 0｜申込み・事前アンケート（非同期）
ヒアリングシート（後述）の簡易版をフォームで回収。参考にしたいサイトのURL・スクショ（「いいな」集め）もここで宿題として依頼する。
→ ミーティングを「聞く時間」ではなく「決める時間」にするための仕込み。**事前ミーティングの質はここで半分決まる。**

### STEP 1｜戦略設計ミーティング（90分・オンライン）
dododoの設計観点をアジェンダにして、その場で決め切る：
1. **何を作るか** — LP1枚か、Webサイト型か（商品が複数・実績も見せたい→サイト型）
2. **ゴール** — 購入／LINE登録／予約／無料相談／問い合わせ、のどれか1つに絞る
3. **導線** — どこから来て（Threads/Instagram/LINE/紹介/検索）、どこへ進むか。流入元で冒頭の言葉を変える
4. **誰に** — 初心者か比較検討中か。読者の「今の状態」を言語化
5. **世界観** — 集めてもらった「いいな」をその場でAIに言語化させ、方向性を2〜3案に絞る

### STEP 2｜設計図の納品（3営業日以内）
- 事業設計図（コンセプトシート）：ターゲット定義／ゴールと導線図／訴求の優先順位／世界観の言語化
- FVイメージ2〜3案（画像で確認。「高級感」の解釈ズレをここで潰す）
- 顧客がFV案と世界観を選んだら制作着手

### STEP 3｜制作（5〜7営業日）
内部でメーカー→Codexルートで実装。修正は「1回に1箇所」の原則で回す。

### STEP 4｜検品・QAループ
5チェック＋成約率診断＋スマホ実機確認。嘘の実績・架空レビュー・煽り表現が入っていないかも必ず確認（信頼を削る表現は静かに削る）。

### STEP 5｜公開・納品ミーティング（30分）
Vercel等で公開しURL納品。HTML一式も渡す（顧客の資産として残る）。告知文セット（Threads3本＋LINE配信文）を渡し、「公開してからが本番。反応を見て直す」ことを伝える。
→ ここが上位プラン（公開後の改善・横展開の並走）への自然なブリッジになる。

## 4. 事前ミーティング用ヒアリングシート

dododoの設計観点＋ゆめのヒアリング7問を統合した独自シート。事前アンケート（★のみ）とミーティング本番の両方で使う。

### A. 商品の核（ゆめの7問ベース）
1. ★何を届けますか？
2. ★誰に届けたいですか？（過去の自分と同じ場所にいる人を具体的に）
3. ★その人のいちばんの悩みは？
4. ★使うと、どう変わりますか？
5. 中身・内容は？
6. 安心材料は？（実績・FAQ・返金・注意事項。「なし」なら正直に「なし」）
7. ★ゴールと価格は？

### B. 導線（dododoベース）
8. 読者はどこから来ますか？（Threads / Instagram / LINE / 紹介 / 検索 / 既存客）
9. ページで最終的にしてほしい行動は1つに絞ると何ですか？
10. その後の流れは？（例：LP→LINE登録→無料相談→購入）
11. LP1枚で足りますか、サイト型が必要ですか？（商品数・見せたい実績の量で判断）

### C. 世界観
12. 「いいな」と思うサイト・ページを3つ（業種違いOK。スクショ推奨）
13. 欲しい雰囲気／避けたい雰囲気（例：高級感は欲しいが冷たくしたくない）
14. NG要素（使いたくない色・言葉・表現）

### D. 検品基準（受注時に合意しておく）
- 主役は1つか／誰向けか3秒で伝わるか／CTAに迷いがないか／安心材料があるか／煽っていないか

## 5. なぜ「コンサル並みの成果」と言えるのか（サービスの根拠）

顧客の手元に残るもの：
1. **事業設計図** — LP以外（SNS投稿、商品説明、営業トーク）にも流用できる言語化資産
2. **導線図** — 集客からゴールまでの全体像。次の商品を作るときの土台
3. **完成LP＋HTML一式** — 人に送れるURL。資産として手元に残る
4. **告知文セット** — 公開直後の集客の初速

「LPを納品して終わり」ではなく「事業の見せ方が決まった状態」を納品するので、成果物の再利用性が高い＝コンサルと同じ構造。ここを販売LPでも一貫して語る。
