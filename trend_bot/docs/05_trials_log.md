## 3. 開発中に見つけて直した不具合（成績を良く見せる変更ではなく、誤評価を防ぐ修正）

| 発見方法 | 内容 | 影響 |
|---|---|---|
| 未来情報テスト（`test_prepared_arrays_are_point_in_time`） | 相関推定で未完了の週ブロックが窓に入り、全データ版と途中打切り版で相関が異なった | 完了ブロックのみ使用に修正 |
| 同上 | 相関の再推定タイミングがループ開始位置に依存（バックテストと模擬運用で不一致の原因） | 位置に対して決定的な再推定スケジュールに修正 |
| 同上 | 市場の「データ終了」を最終データ日で判定しており、休場日と区別できていなかった | 過去データだけで判定する「古さ」基準に変更 |
| 模擬運用 = バックテスト一致テスト | `decide()` が各市場の将来の最終データ日を参照（未来情報） | 同上の修正で解消し、NAV が 1e-10 の精度で一致 |
| 模擬運用テスト | 判断日の当日データ欠損を 1 営業日まで許容していた | 当日必須（`max_data_age_business_days: 0`）に変更 |
| 評価結果の点検 | ショック試算で未開始市場の NaN が合計を 0 にしていた | 修正 |
| 月次データ読込 | 未完了の当月を月末日付で記録していた（未来日付） | 未完了月を除外 |
