# 01. 戦略仕様書（基準戦略 v0.1）

最終更新: 2026-09-27。パラメータの正本は `config/strategy.yaml`（日次）と `config/strategy_monthly_proxy.yaml`（月次代替データ用の上書き）。

## 1. 位置付け

- 目的: 複数資産（株価指数・国債・通貨・商品）の先物で、中長期トレンドに追随する単純で説明可能な基準戦略。
- 研究上の仮目標（**予測でも実績でもない**）: 短期安全資産に対し長期平均で年率 +3〜5pt、BOT 割当資金全体の年率ボラ 8〜10%。
- 目標ボラは最大損失の上限ではない。瞬間ショックの試算（評価レポート §6）では、全保有市場が同時に 5σ 逆行した場合の損失は NAV の 2 割前後に達しうる。

## 2. 使用データ

| 用途 | データ | 備考 |
|---|---|---|
| シグナル・ボラ | 市場ごとの **連続系列**（保有限月の日次清算値差の累積） | 限月間の価格差を含まない |
| 損益 | **実際に保有した限月** の清算値 × 乗数 × 枚数 | 乗り換えは旧限月の売り・新限月の買いを別々に約定・コスト計上 |
| 円換算 | 市場の建値通貨→円の為替（判断日の値） | 代替データでは FRB H.10（NY 正午） |
| 流動性 | 保有限月の出来高 20 日平均（1 日ラグ） | 無い場合は研究用仮定（`assumptions.yaml`） |

## 3. シグナル（数式）

市場 i、市場自身の取引日 t（バー）について:

```
dP_t      = P_{c(t-1)}(t) − P_{c(t-1)}(t−1)        c(t−1) = 前日に保有対象だった限月
A_t       = Σ dP                                    連続系列（水準に意味はなく差だけを使う）
σ_t       = sqrt( EWMA_span(dP²) )                  span = 60 バー（日次）/ 24（月次）
floor_t   = 0.5 × median(σ, 過去 1260 バー)          ボラ推定の下限（過小推定による過大建玉を防ぐ）
σ*_t      = max(σ_t, floor_t)
z_{L,t}   = (A_t − A_{t−L}) / (σ*_t × √L)            L ∈ {63, 126, 252}（約 3・6・12 カ月）
f_{L,t}   = sign(z_{L,t})                            基準案（代替: clip(z/1, −1, 1)）
F_t       = mean_L f_{L,t}  ∈ {−1, −1/3, +1/3, +1}   判断が割れると |F| が小さくなる
```

- 価格の「差」だけを用いるため、価格がゼロ近傍・マイナス（WTI 2020-04-20）でも破綻しない。騰落率・対数収益率は使わない。
- 月次代替データでは平均値系列による人工的な自己相関を避けるため F を 1 バー追加で遅らせる。

## 4. 目標建玉

```
w_i   = 資産分類の予算（各 1/4、データのある分類で再正規化）を分類内の sector で等分し、さらに市場で等分
IDM   = min(2.5, 1/sqrt(wᵀ C⁺ w))    C⁺ = 週次（5 バー合計）正規化リターンの相関（負は 0 に切上げ）、直近 104 週
v_i   = σ*_i × √252 × 乗数_i × FX_i   （1 枚あたりの年率円建てボラ）
N*_i  = w_i × IDM × 目標ボラ(9%) × NAV / v_i        （|F|=1 のときの建玉）
T_i   = F_i × N*_i × DD倍率
```

## 5. リスク上限（すべて縮小方向のみ、`risk` セクション）

| 項目 | 既定 |
|---|---|
| 1 市場の単独年率ボラ | ≤ 3% of NAV |
| sector（経済的に似たリスク）ボラ | ≤ 5% |
| 資産分類ボラ | ≤ 6% |
| ポートフォリオ事前推定ボラ | ≤ 目標 × 1.25 |
| 1 市場の想定元本 | ≤ 1.5 × NAV |
| 総想定元本 | ≤ 6 × NAV |
| 当初証拠金 / NAV | ≤ 30% |
| (NAV − 当初証拠金 − 3σ 日次損失) / NAV | ≥ 60% |
| 建玉 / ADV | ≤ 5% |
| 損失拡大時の縮小 | DD 10% → ×0.75、15% → ×0.5、20% → ×0.25。閾値 −2.5pt まで回復で 1 段階戻す |

- 整数化後に上限を再検査し、違反があればリスク寄与の大きい市場から 1 枚ずつ減らす。
- 目標ボラに届かなくても建玉を増やさない（上限超過時の縮小のみ）。
- 証拠金はボラ上限とは別の制約。証拠金が小さい市場も経済的リスク（ボラ・想定元本）で制限される。

## 6. 注文生成

1. 目標（整数）と現在建玉の差が `buffer_frac(10%) × |N*|` 以内なら取引しない。超えたらバッファの端まで取引する。
2. リスク増加分のみ 1 日の変更量上限（`0.5 × |N*|`）と停止時の禁止を適用。削減は常に可（流動性上限のみ）。
3. 1 日の注文枚数 ≤ `1% × ADV`。
4. 限月到来: 保有限月の基準日（第一通知日と最終取引日の早い方）の 5 営業日前に保有対象を次限月へ切替え → 旧限月の決済と新限月の建てを同日に発注（停止中は新限月を建てない）。
5. 注文 ID = 判断日・市場・限月・数量・理由のハッシュ（同じ判断は同じ ID → 再送しても重複しない）。

## 7. 時刻・約定の仮定

| 事象 | 時刻 |
|---|---|
| データ観測 | 各市場の日 t 清算値確定後（例: CME は CT 午後、OSE は JST 15:45 以降、Eurex は CET 夕方） |
| 判断 | 全市場の日 t の値がそろった後（運用想定: 翌営業日 JST 07:00 に一括） |
| 発注 | 各市場の t+1 セッション |
| 約定価格の仮定 | **t+1 の清算値** ± コスト（手数料＋半スプレッド＋インパクト `0.1 × σ_日 × √(枚数/ADV)`） |
| 約定不能 | t+1 が休場・取引停止（status=halt）・値幅制限（status=limit）の場合は次の取引可能日まで持ち越し |
| 遅延ストレス | t+2 約定（`execution.lag_bars=2`） |

同日終値での判断・約定は設定検証で禁止している（`lag_bars >= 1`）。

## 8. 会計

- 通貨別現金残高に毎日の値洗い（変動証拠金）を計上。建玉の含み損益は毎日実現するため二重計上なし。
- 現金利息は実際の現金残高にのみ付く（想定元本には付かない）。JPY 短期金利は未入手のため 0 とし、成果物に `cash_rates_missing` を表示。
- 外貨残高は月末に円転（コスト 2bp、仮定）。為替換算損益 = 前日外貨残高 × 為替変化。
- 日次の恒等式 `ΔNAV = 先物損益 + コスト + 利息 + 為替換算 + 円転コスト` をテストで検証。
