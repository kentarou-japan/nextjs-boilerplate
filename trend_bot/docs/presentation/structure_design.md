### A-2. 中心命題

「システムは研究・模擬運用の基盤として動くが、戦略の収益性は実先物データでまだ確かめられておらず、実資金は入れず再検証から始めるべきだ。」

### A-3. 読者へ残す重要ポイント（5）

1. 動くこと（ソフトウェア）と儲かること（戦略）は別に判定した
2. 何を作ったか：データ取得から模擬運用まで同じ判断コードで動く仕組みと、増やさない守り
3. 先物の実データは取得できず、成績は代替データの予備検証
4. 結果：正の超過収益は出たが、単純な分散投資や単一期間版を上回らず、最終評価期間は食い違った
5. お願い：実資金ではなく、実データでの再検証に進むかの判断

## B. 設計判断

### 意思決定ブリーフ

| 項目 | 内容 |
|---|---|
| 読者の現在地 | トレンド追随も今回の作業も初めて聞く。「AIで儲かるBOTができた」と誤解しうる |
| 読後状態 | 何を作り、何が確かめられ、何が確かめられていないかを説明でき、次段階の可否を判断できる |
| 最終行動 | 決裁者が「実先物データを購入して再検証へ進むか」を決める |
| 判断条件 | システムの信頼性、成績の水準と比較、データの制約、費用（データ購入）、合格条件 |
| 止まる不安 | 本当に儲かるのか／実資金を入れる話か／費用がかかるのか／壊れたら損が膨らまないか |
| 最終決定者 | 運用の意思決定者（社内） |
| 制約 | 社内限定、投影、15 ページ前後 |

### 構成型の選択
- **採用：経営会議・エグゼクティブ報告（主）＋稟議・意思決定（副）**。結論を先に置き、根拠、リスク、判断依頼で閉じる。
- 次点：説明・概念理解（セミナー型）。初見の読者には合うが、最終行動（判断）への直結と、リスク・不安の処理が弱いため不採用。仕組みの説明は章1に 1 ページだけ取り入れた。
- 原文（検証レポート）の順序から変えた主要 3 点：①結論を §10 から冒頭へ移動 ②レポートにない「トレンド追随とは」を初見向けに追加（S02 から構成）③詳細な表（ストレス・容量・感度）は本編から外し別紙へ。

円建て・複数資産トレンド追随BOT → 仕組みは使える。実資金はまだ入れない → 3つの問いで説明します → 何を作ったか → 上がり続けるものを買い、下がり続けるものを売る → データから注文まで、同じ判断で動く → 上限は減らす方向にだけ働く → 壊して確かめ、設計どおり止まった → 何が分かったか → 先物の実データは手に入らなかった → 年2%台の上乗せ、ただし下落は大きい → 単純な分散投資を上回らなかった → 最後の期間の結果は、データで大きく割れた → 言えることと、まだ言えないこと → 次は実データで確かめる段階です

### 30秒要約
先物のトレンド追随BOTを、データ取得から模擬運用まで一通り作り、壊れても止まることを確かめました。ただし先物の実データが手に入らず、代わりのデータで試した成績は年2%台の上乗せにとどまり、単純な分散投資を上回りませんでした。実資金は入れず、まず実データを買って再検証するかをご判断ください。

## E. 画像制作の設計（full_deck）

### STYLE DNA（全ページで一字一句同じ文を使う）
16:9、上下左右に画面幅5%以上の安全余白。ベースは温かい生成りの紙色、主色は深い紺（見出し・線・図形）、アクセントは朱色を1ページ1か所だけ（結論・判断・注意の強調）。書体は端正な明朝体の見出しと、読みやすい角ゴシックの本文。見出し・本文・注記の3階層で、大きさの差をはっきり付ける。線は細く一定の太さ、角は小さく丸め、影や光沢は使わない。背景はかすかな紙の質感のみ、光は均一でフラット。余白を広く取り、1ページの主役は1つ。写真と人物は使わず、図解と大きな数字だけで構成する。右下に「NN / 15」のページ番号、左下に小さな資料名。表紙は交差する上昇線と下降線を主役に、落ち着いた信頼感を出す。禁止：PowerPoint・Canvaの量産テンプレ風、UIダッシュボード風、グラデーション、ネオン、コインや札束・ロケット・右肩上がりの矢印などの「儲かる」イメージ、架空の数字やロゴ。

（見た目の方向：executive clean × evidence board）

### 固定部品契約（草案）

| 部品 | 固定内容 |
|---|---|
| 安全余白 | 上下左右 5% 以上 |

### CTA契約
- 役割：decision（判断依頼）
- 位置：P15 の下部、全幅の帯
- 外形：朱色の細い下線付きの帯（塗りつぶしなし）
- マーク：小さな紺の四角1つ（行頭）
- 文体：「〜かをご判断ください」で終える1文、補足は1行まで
- 文言（案）：「実先物データを購入し、再検証へ進むかをご判断ください」／補足「実資金の検討は、その結果を見てから」
- 本文ページ下部の橋渡し帯は置かない（話者が口頭でつなぐ）

### 表紙のデザインサンプル方針
生成り地に、紺の上昇線と下降線が画面中央で交差する抽象図を大きく。左上に明朝の大見出し「円建て・複数資産トレンド追随BOT」、その下に副題、右下に日付。朱色は副題の一語（「分けて判定」）だけ。

### 生成計画と注意
1. 構成承認後、表紙1枚だけ生成して承認を待つ
2. 承認後、本編標準（P11）→ 検品 → CTA標準（P15）を1枚ずつ生成し、書式の承認を待つ
3. 承認後、残り12ページを1枚ずつ直列生成・原寸検品
4. 選んだ形式へ組む

- 画像生成は外部サービス（Higgsfield）。日本語文字の描画品質は未検証。崩れた場合は、文字を後から重ねず、文字量を減らして再生成する（同じ問題は原則2周まで。2周で直らなければ相談）。
- 数字は各ページ4個までとし、原稿と一字ずつ照合する。精密な表は画像にしない。
- 社内限定資料の文言・数値を外部サービスへ送ることになる（ユーザー選択済み）。
