## 0. 前提の揃え方

- 評価通貨: 円。先物損益・コストは建値通貨で計上し日次の為替で円換算。
- 収益は **短期安全資産に対する超過収益** の近似（JPY 短期金利データ未入手のため現金利息 = 0）。
- 費用: 手数料・半スプレッド・インパクト（研究用仮定）を全比較対象に同一ルールで適用。B は 10bp/回転。
- 代替データの偏り: キャリー（金利差）、ロールイールド、配当−金利を含まない。月次は平均値系列を含み 1 カ月の追加ラグで対処。
- 資金 3 億円・整数枚数（容量分析で 1 億・10 億）。

## 10. 結論（ソフトウェアと投資戦略を分けて判定）

### ソフトウェアとして
- データ→シグナル→建玉→リスク→注文→約定→会計→レポート→模擬運用が同じコードで動作し、57 件のテストが合格（未来情報、乗り換え、値洗い、為替、負価格、リスク上限、重複注文、再起動照合、停止・再開など）。
- 合成ランダムウォーク上の Sharpe は −0.04（未来情報の混入を示す兆候なし）。
- 判定: **研究・模擬運用の基盤としては使用可能**。本番接続は阻害条件 42 件が残るため不可。

### 投資戦略として
- 言えること: 代替データの開発期間で Sharpe 0.5 前後の正の超過収益、株式との相関はほぼゼロ、コスト倍増でも正を維持。パラメータ選択による上積みはなく、PBO は 0.5 未満。
- 言えないこと: 実際の先物（キャリー・ロール・実コスト込み）での収益性、目標年率 +3〜5pt の達成見込み、危機時の下支え効果、複数期間合成の優位性、大口時の執行可能性、日本・欧州株価指数、独・日・英国債での有効性（データなし）。
- 根拠の強さ: 弱い。最終評価期間の日次代替は Sharpe 0.14・DD −20%、比較対象 B や C を上回っていない、成績の多くが株式ロング・金・特定期間に集中。
- **提案: 現時点では実資金での採用を見送り、実先物データでの再検証（08 の条件）を次段階とする。**
